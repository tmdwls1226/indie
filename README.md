# TURNBOUND

React + TypeScript + Vite로 만든 브라우저 턴제 RPG입니다. 3 대 3 파티 전투, 레벨 100 성장, 4단계 전직 트리, 장비·보스·퀘스트를 갖춘 싱글 플레이 PvE 게임입니다.

## 실행 방법

```bash
npm install
npm run dev
```

터미널에 표시된 로컬 주소(보통 `http://localhost:5173`)를 브라우저에서 여세요. 빌드는 `npm run build`입니다.

## 게임 구성

- **마을**: 출전(스테이지 선택) · 영웅·장비 · 전직·스킬 · 상점 · 퀘스트
- **전투**: SPD 기반 행동 순서, 스킬(MP·재사용 대기), 상태 이상 16종, 광역·연쇄·다단 히트, 부활, 궁극기 연출, 자동 전투
- **성장**: 레벨 1~100, 전직 관문 Lv.10 / 30 / 70 / 100 (전직 시험 전투 통과 필요), 스킬 슬롯 3 → 4 → 5 → 6
- **전직 트리**: 전사(공격형·방어형), 마법사(화염·빙결·뇌전), 성직자(공격·심판형, 회복·지원형)
- **콘텐츠**: 5개 챕터(납골당 · 검은숲 · 벨카르 · 모르가스 · 아르카) 49개 스테이지와 챕터 보스 5종, 전직 시험 4개, 10단계 장비 등급(160종), 퀘스트 26개, 영웅 스킬 51개
- **저장**: 상태가 바뀔 때마다 자동 저장 + 30초 주기 저장 + 수동 저장. 체크섬 검증과 직전 백업으로 손상 복구. 전투 중 새로고침해도 이어서 진행됩니다.

## 폴더 구조

| 경로 | 역할 |
|---|---|
| `src/engine/` | 전투 엔진(`battleEngine`), 자동 행동 AI(`ai`), 성장·장비·퀘스트(`progression`), 보상 정산(`game`), 저장(`save`) |
| `src/data/` | 스킬, 직업, 몬스터, 스테이지, 장비, 퀘스트 데이터 |
| `src/components/` | 전투 화면, 명령창, 로그, 결과 화면, 설정 / `town/`: 마을 각 탭 |
| `src/dev/sim.ts` | 밸런스 시뮬레이터 (앱에는 포함되지 않음) |

## 이미지 에셋

영웅·몬스터·보스·배경·아이콘은 `public/assets`의 PNG를 자동으로 불러오고, 파일이 없으면 이모지로 대체합니다. 파일명 규칙과 크기는 [public/assets/README.md](public/assets/README.md)에 있고, 설정(⚙) → "에셋 현황"에서 우선순위(P0~P2)별로 어떤 파일이 있는지 확인할 수 있습니다.

현재 들어 있는 이미지는 콘셉트 시트 조각(`TURNBOUND_PNG_분할_에셋`)을 `node scripts/import-split-assets.mjs <폴더>`로 자동 변환한 **임시 이미지**입니다. 같은 파일명으로 투명 배경 PNG를 넣으면 바로 교체됩니다.

## 밸런스 조정

적 수치는 `src/data/monsters.ts`의 기본 곡선과 `LEVEL_MULT` 보정 테이블, `BOSS_TUNE`으로 정해집니다. 값을 바꾼 뒤에는 개발 서버를 연 상태에서 브라우저 콘솔로 시뮬레이터를 돌려 확인하세요.

```js
const sim = await import('/src/dev/sim.ts');
sim.evalGrid([10, 30, 50, 70, 100], 20);          // 레벨별 일반 전투 승률·잔여 HP·라운드 수
sim.evalGrid([10, 30, 50, 70, 100], 20, { boss: true });
const r = sim.runCampaign({ seed: 1 });            // 처음부터 Lv.100까지 자동 플레이
sim.zoneSummary(r.rows);
```

> 콘솔에서 수치를 바꿀 때는 `sim.tune`으로만 수정하세요. Vite의 HMR 때문에 모듈을 따로 import하면 시뮬레이터가 보는 것과 다른 복사본이 만들어질 수 있습니다.

## 설정 메뉴의 테스트 도구

설정(⚙) → "테스트 도구"에는 골드 추가, 레벨 +10, 전직 시험 즉시 통과, 모든 스테이지 해금이 있습니다. 후반 콘텐츠를 확인하기 위한 개발용이며 배포 전에 제거해야 합니다.

## 범위

온라인 기능(계정, PvP, 랭킹)은 구현하지 않았습니다. 저장 코드는 `src/engine/save.ts`에 모여 있어 이후 서버 저장으로 바꾸기 쉽습니다.
